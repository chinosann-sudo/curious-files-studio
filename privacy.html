Privacy policy.

How the personal-use Curious Files Studio application and this website handle data.

Effective date: 10 October 2026 · Operator: individual creator of Curious Files Studio

Scope: Curious Files Studio is a private video-generation and upload tool used by its owner. This public website is informational only. It does not offer a public YouTube login or account registration.

1. Use of YouTube API Services

Curious Files Studio uses YouTube API Services (the YouTube Data API v3) to upload a video to a YouTube channel that the operator has explicitly authorized through Google's OAuth process. The requested permission is https://www.googleapis.com/auth/youtube.upload.

The tool does not request access to Gmail, Google Drive, YouTube viewing history, subscriber information, private playlists or other channel-management data. It does not provide third-party user registration.

2. Information used and stored

  • OAuth credentials: The owner provides a Google OAuth desktop client and authorizes uploading. The resulting client identifier, client secret and refresh token are stored on the operator's device and as encrypted GitHub Actions Secrets in a private repository. Access tokens are obtained when needed for uploads.
  • Video files and text: Original script text, illustrations, narration, subtitle files and video metadata are generated in private GitHub Actions jobs and may be retained as temporary workflow artifacts. The current artifact-retention setting is two days; GitHub Actions logs follow the separate repository/host retention settings.
  • Upload results: YouTube returns a video ID and private-visibility status. The application may store these in temporary GitHub Actions output and logs so the owner can verify the result.
  • Website visitors: This static site has no analytics scripts, advertising trackers, embedded YouTube player, browser storage, cookies set by our code, forms or logins. The GitHub Pages hosting service may process ordinary server/network requests under GitHub's own policies.

3. How information is used and shared

OAuth credentials are used only to obtain Google access tokens to perform the uploads requested by the owner; they are not sent to Gemini. Video files and metadata are transmitted to YouTube as part of uploads. Non-personal scientific script prompts are submitted to the Google Gemini API to help draft narration. GitHub provides the cloud processing environment and storage for private workflow artifacts. The public website does not sell personal information or share authorized YouTube account data with advertisers.

See Google's Privacy Policy, GitHub's Privacy Statement, and YouTube's Terms of Service for those services' own processing practices.

4. Control, revocation and deletion

The operator can stop uploads by disabling GitHub workflows and deleting the YOUTUBE_OAUTH_JSON secret. Google access can also be revoked in Google Account security permissions. Upon revocation, stored OAuth credentials and any remaining authorized YouTube API data in the operator-controlled workflow environment should be removed promptly, no later than seven calendar days. GitHub-hosted logs and artifacts may have separate retention mechanics.

For a data access or deletion request, contact the operator through the public issue tracker. Please do not include personal details or credentials in a public issue; request a private contact method if necessary. Deleting data kept by the tool does not delete a video already hosted by YouTube. To remove an uploaded video, the owner must delete it from YouTube Studio.

5. Security and retention

Workflow code and credentials are stored in private GitHub resources; credentials are not published to this website. The current uploader requests private visibility and does not automatically publish public videos. Access should be limited to the operator's authorized GitHub and Google accounts. We retain operator-controlled API data only for the purposes described above and delete it when no longer needed or authorization is withdrawn.

6. Changes and contact

If the application's features, data use, or available user base change, this policy will be revised before those changes are introduced. For questions or data requests, use the Curious Files Studio contact issue tracker without posting sensitive information publicly.

Curious Files Studio is an independent project and is not affiliated with or endorsed by Google or YouTube.
