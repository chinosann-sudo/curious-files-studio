What we make

Small videos. Big questions.

The project explores science, astronomy, nature and surprising facts. Content is developed from an operator-maintained collection of topics with source references.

01 / RESEARCH

Source-grounded scripts

The operator maintains topic notes and references. Gemini assists with rewriting narration; generated claims need human review.

02 / PRODUCTION

Illustrated short videos

Python, offline text-to-speech, graphics and FFmpeg create narrated vertical MP4 videos with embedded timed captions.

03 / DISTRIBUTION

Owner-authorized uploads

GitHub Actions runs the private software. The YouTube Data API uploads videos only to a channel explicitly authorized by the operator.

Application overview

Simple by design.

01

Topic selection

A science fact is selected from a small, curated and source-linked topic set. The app currently does not discover new trending facts autonomously.

02

Script & video production

Google Gemini helps draft narration. Locally running voice and video tools produce the video and captions in a GitHub Actions cloud job.

03

Authorized YouTube upload

The operator grants YouTube upload permission using Google's OAuth authorization. The current workflow uploads a single private video only after manual confirmation.

For reviewers: This is a personal-use, non-public API client—not a public video editor, login service, subscription, or e-commerce product. The public pages here describe its operation and data practices. The source repository and OAuth credentials are private; a demonstration may be supplied separately on request.

Transparency

Data practices, clearly stated.

The website has no accounts, contact form, analytics scripts or advertising cookies. The private uploader uses only the Google OAuth permission required to upload videos to its owner's channel.
